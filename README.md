# Programmierkurs für Peer

Willkommen zu deinem persönlichen Programmierkurs! Hier lernst du JavaScript, React und wie man coole Spiele programmiert.

## Setup - So gehst du vor:

### 1. VS Code installieren (falls noch nicht geschehen)
- Gehe zu: https://code.visualstudio.com/
- Lade VS Code herunter und installiere es
- Das ist kostenlos!

### 2. Dein erstes Projekt starten

#### Variante A: Mit Claude Code (empfohlen)
1. Öffne das Terminal/Claude Code
2. Navigiere zu diesem Ordner: `/Users/mworobcuk/Programmierkurs`
3. Sage mir einfach: "Ich möchte anfangen!" oder "Hilf mir, mein erstes Spiel zu programmieren!"
4. Ich erstelle dann die Dateien für dich
5. Öffne die erstellten Dateien in VS Code

#### Variante B: Direkt in VS Code
1. Öffne VS Code
2. Klicke auf "File" → "Open Folder"
3. Wähle den Ordner `/Users/mworobcuk/Programmierkurs`
4. Erstelle neue Dateien über "File" → "New File"

### 3. Deine Projekte testen

Für HTML-Projekte:
1. Finde deine `.html` Datei im Finder
2. Doppelklick → öffnet sich im Browser
3. Oder: Rechtsklick in VS Code → "Open with Live Server" (wenn installiert)

## Hilfreiche VS Code Extensions (Optional)

Diese kannst du später installieren, sind aber nicht zwingend nötig:
- **Live Server** - Zeigt deine Webseite sofort im Browser an
- **Prettier** - Macht deinen Code schöner
- **Auto Rename Tag** - Hilft bei HTML-Tags

## Wie der Kurs funktioniert:

### Option 1: Eigene Projekte
- Du hast eine Idee für ein Spiel oder Projekt?
- Sag mir einfach, was du machen möchtest
- Ich helfe dir dabei, es umzusetzen!

### Option 2: Strukturierter Kurs
- Ich führe dich Schritt für Schritt durch verschiedene Projekte
- Wir fangen ganz einfach an und steigern den Schwierigkeitsgrad
- Du lernst dabei alle wichtigen Konzepte

## Ordnerstruktur

Deine Projekte werden hier organisiert:
```
Programmierkurs/
├── projekt-01-hallo-welt/
├── projekt-02-klick-counter/
├── projekt-03-farben-wechsler/
└── ... weitere Projekte
```

Jedes Projekt bekommt seinen eigenen Ordner - so bleibt alles übersichtlich!

## Bei Problemen oder Fehlern

Keine Panik! Fehler sind völlig normal beim Programmieren.

So gehen wir vor:
1. Zeige mir den Fehler (Screenshot oder kopiere die Fehlermeldung)
2. Zeige mir deinen Code
3. Ich schaue mir alles an und helfe dir
4. Wir beheben den Fehler zusammen
5. Du lernst dabei, wie man debuggt!
