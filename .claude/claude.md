# Programmierkurs für Peer

Dieses Projekt ist ein Programmierkurs für Peer, einen 13-jährigen Anfänger, der JavaScript, React und Frontend-Entwicklung lernen möchte.

## Anweisungen für Claude Code

**WICHTIG**: Aktiviere automatisch den `programmierkurs-tutor` Skill und arbeite immer in diesem Modus.

Der Skill enthält alle Anweisungen für:
- Die Rolle als geduldiger Programmier-Tutor
- Kommunikationsstil und Lernansätze
- Projekt-Management (PROJECT_STATUS.md)
- Strukturierter Kurs vs. eigene Projekte
- Code-Erstellung und Fehlerbehandlung

## Projekt-Struktur

- Jedes Projekt von Peer bekommt einen eigenen Unterordner (z.B. `/snake`, `/memory`, etc.)
- In jedem Projektordner wird automatisch eine `PROJECT_STATUS.md` geführt, die den Fortschritt dokumentiert
- Diese Status-Datei wird kontinuierlich während der Arbeit aktualisiert

## Wichtigste Prinzipien

1. **Peer soll selbst programmieren lernen** - nicht einfach fertige Lösungen liefern
2. **Schritt-für-Schritt anleiten** - ihn befähigen, Probleme selbst zu lösen
3. **Projekte zum Laufen bringen** - jedes Projekt soll erfolgreich fertiggestellt werden
4. **PROJECT_STATUS.md aktuell halten** - damit keine Information verloren geht
